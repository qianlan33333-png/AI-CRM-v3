# 问卷管理展示与上线状态修复

## 目标

一级问卷管理列表以问卷名称（`name`）作为主信息和检索字段；问卷标题（`title`）继续用于答题和预览。二级编辑页不提供分享入口，一级列表保留现有分享操作。

保存原本已发布且启用的普通问卷时，编辑器在保存新定义后显式发布，并通过服务端读回确认本次版本仍为启用和上线。保存草稿、已停用问卷，或用户本次勾选停用时，不自动发布。

## 范围与验收

- `name=黄小璨激活问卷-新书赠送`、`title=激活黄小璨AI登记` 时，一级列表显示和检索前者；编辑器与答题/预览仍使用后者。
- 二级编辑页不显示“分享”；一级列表仍显示原有“分享”。
- 已上线普通问卷保存后仅以 `/public-publish` 返回的准确版本和 GET 回读确认上线。发布或回读失败显示真实的“当前为草稿”或“发布状态未确认”，不假报上线。
- 测评页既有“保存并发布”桥接保持兼容；普通页不触发该桥接的重复发布。

## 已核对的契约与组件

- [PR #45](https://github.com/qianlan33333-png/AI-CRM-v3/pull/45) 的响应同时提供 `name` 和 `title`，因此一级展示只转换现有 DTO，不改接口或数据模型。
- [PR #43](https://github.com/qianlan33333-png/AI-CRM-v3/pull/43) 的回归夹具已区分 `name=Imported questionnaire` 与 `title=Stale title`；本次沿用该语义验证检索和显示。
- 复用 `RenderSurvey`、冻结列表的 table/search/action 和 `questionnaireEditor`。`surveyAdapter` 仅在同一运行时图中于冻结 main 前转换列表字段，不新增页面或组件。

## 验证

- 列表 bridge 回归：问卷名称能检索和显示，问卷标题不能命中名称检索，原始 DTO 在渲染后恢复。
- 编辑器回归：已上线问卷保存后以保存返回的版本显式发布并 GET 回读；用户勾选停用时不发布；二级页无分享。
- 构建、Survey release asset closure，以及 Survey/WebShell Go 测试通过。

## 架构分类

不涉及 OneID/外部身份：只呈现问卷定义元数据。涉及既有 Survey 本地事务状态写：保存和版本化发布继续使用现有 Survey Owner 的接口；不新增表、队列或外部效果。
