# 本地交付审查清单

本文件记录需要由实现和可复现测试共同证明的边界。列入清单不表示已通过；最终结果以验收记录为准。

## 凭据与上传

- 图片缓存按作用域、类型与冻结内容摘要共享；不同引用或展示文件名不导致同一图片重复上传。附件保留必要文件名语义。
- 有效期使用 Provider 返回的创建时间加 72 小时，不能用本地收包时间向后延长；合法的成功响应可省略 `errcode`。
- 上传超时独立于消息超时，本地慢响应验证不会被原 8 秒客户端超时提前终止。
- 明确拒绝与网络未知分开；HTTP 网关错误不能被当作已证明未产生效果。
- 刷新失败保留有效旧凭据；页面同时显示最近刷新异常和旧凭据有效状态。
- 未知效果跨日、手动刷新仍不会换键重传。业务内容摘要不包含轮换凭据。

## 每日轮次与并发

- 同日自动轮次唯一；手动操作按操作者与幂等键独立，重复请求重放，内容漂移返回冲突。
- 每轮按唯一上传文件记录成员；成员可引用另一轮尚未完成的准备任务，统计不能漏掉它。
- 分页游标和成员计数事务提交；重试、双 Worker、进程重启不会重复计数或重传已成功文件。
- 单个原文件缺失或不可支持能记录异常并继续，不永久卡住整轮游标。
- 02:00 停机后的启动补建遵循当天到点条件，02:00 前不提前启动当天轮次。
- 使用实际 River 与阻塞本地 Provider 验证 Excel 3 并发、素材上传 2 并发；发送等待素材释放槽且不记作消息尝试。

## 素材库与业务入口

- 并发同图上传仅复用启用图片；停用不自动恢复；相同幂等键重试保持最初绑定。
- 选用已有图检查 PNG/JPEG 与封面大小；文件替换、换图重审，提交后不可改，历史字节保留。
- API 的权限、CSRF、输入错误、幂等冲突、不存在、临时不可用分别按契约响应。
- Excel、AI 助手、自动化、侧边栏、群运营逐入口验证统一准备；无旧逐消息上传旁路。
- 页面采用真实 DTO，缺失时间为不可用，受理不等于成功；刷新请求未知时重用原操作键。

## 交付证据

- 真实隔离 PostgreSQL 专项、完整迁移与旧测试 fixture 更新。
- 全仓快速门禁及编译、完整受影响前后端阶段、构建后 Chromium + 本地 Provider 旅程。
- 记录所有未验证项；不推送、不部署、不修改生产、不进行真实企微上传或发送。

## 完整回归发现的追加检查

- 实际 Media Host 必须加载 `materialSaveHost`；不能仅在 JSDOM 手动注入脚本后证明界面可用。
- 原文件缺失的扫描失败必须在 API 与页面定位到素材并提示补传，不能从列表静默消失。
- `CoverImageID=0` 的旧 Python Excel 封面保留冻结历史，同时通过统一凭据缓存发送，不能回退为每消息上传。
- EER 的 Retry/Cancel 对真实 Material completion sink 必须原子同步；仅用假 sink 验证队列字段不够。
- 明确限流后自动延迟重试并最终继续，不能只标 `retryable_failed` 后等待人工；未知结果不得进入此链路。
- GroupOps 的接受前准备/冻结与发送前准备都消费统一结果；不能前半段仍依赖未更新的旧媒体回执表。
- 普通人工对账无明确结论时拒绝释放；`no_effect` 与带凭据证据的 `confirmed_effect` 分别原子回写。凭据时间异常必须拒绝，过期证据不能变成有效凭据。
