# 素材分组侧栏与页签筛选修复 PRD

## 业务判断
图片、附件、小程序按各自真实组别筛选。全部分组不限制组别；未分组仅匹配空组别；具体分组精确匹配。切换组别从第一页开始，保留当前素材类型。左侧可滚动分组列表参照现有企微标签管理，右侧保留素材搜索、列表和原有编辑/上传。无需增加独立空组、标签同步或改写素材数据。

OneID: not involved，不读取或变更客户身份。
Persistence: stateless，本次只变更分组展示、查询和路由校验；已有素材编辑事务保持原样。无新增 Provider 调用或异步任务。

## 参考与复用
用户截图及仓库标签管理为主要交互依据。GitHub 参考 https://github.com/ant-design/pro-components 的组合式列表/侧栏模式；不引入新组件框架。三个素材页共享同一分组侧栏组件，数据继续通过 Media 的 facets/groups 接口读取。

## 缺陷与范围
当前 /admin/materials 路由要求查询参数只有 tab；附件选择分组后新增 material_group 被重定向成 images。允许单值 material_group，保留合法 tab，仍拒绝重复/未知参数。全部/未分组/具体分组展示为可点击侧栏，当前项高亮、键盘可操作；分组加载失败显示简短重试信息。

## 验收
- 三个页签均有左侧全部分组、未分组、真实具体分组，右侧正常列表。
- 附件与小程序选择未分组、具体分组、全部后，刷新及重新进入仍保留页签和筛选。
- 中文、空格、特殊字符组名正确编码；分组标题按文本渲染。
- 图片切组与搜索、刷新、重置、上传后组别更新正常，沿用异步请求代际保护。
- 路由单测覆盖合法分组与原有非法参数，浏览器旅程覆盖附件/小程序真实导航和图片侧栏筛选；完整 CI 通过后合并、本地 SSH 部署。
