# 删除/归档闭环 PRD

## 目标

管理员在群运营计划、渠道码、问卷、普通商品、周期商品和优惠券列表中执行“删除”后，资源立即从正常列表和新建选择器中消失；刷新后结果保持。这里的“删除”是各领域 Owner 的可审计归档，不物理删除已被订单、答卷、发送或审计记录引用的数据。

## 业务规则

| 资源 | 用户动作和终态 | 对新入口的影响 | 历史保留 |
| --- | --- | --- | --- |
| 群运营计划 | 任意非归档计划归档 | 默认计划列表和新计划选择不返回；运行时不得创建新的执行 | 计划、节点、群绑定、已接受执行和投递回执 |
| 渠道码 | 归档 | 默认渠道列表不返回；新扫码不触发欢迎语或入渠标签 | 渠道配置、二维码、归因和既有关系 |
| 问卷 | 任意草稿、已发布或已停用问卷归档 | 管理端默认列表和可新开入口不返回；公开页和提交关闭 | 定义版本、答卷、操作收据和审计 |
| 普通商品 | 任意本地生命周期商品归档 | 默认商品列表、商品选择、分享和新结账不可用 | 订单、分销归因、退款、权益和审计 |
| 周期商品 | 归档 | 默认周期商品列表、商品选择和新结账不可用 | 周期订单、已生效权益、成员视图和审计 |
| 优惠券模板/发放定义 | 归档 | 默认模板列表和新发放、领取入口不可用；按既有 Coupon Owner 规则，已领取未使用券也不能再用于新的订单 | 已领取、已核销实例和已下单订单历史 |

归档不是撤销：不会撤销已接受的外部效果、订单、退款、答卷完成回执或已生效权益。已归档对象的历史详情可按已有只读路由读取；归档后不允许重新启用或编辑，除渠道保留既有的显式编辑后再启用规则。

## 架构分类

```text
OneID: not involved. These are本地定义/配置，不解析、创建或关联客户身份。
Persistence: local transaction. 每个领域通过既有 Owner Store、版本/CAS、幂等收据和审计在同一个 PostgreSQL Unit of Work 提交。
External Effects: not involved. 归档不提交 Provider 写入，不建立队列/Worker/重试状态机，也不撤销已接受效果。
```

## 实施边界

- 复用 GroupOps、Channel、Survey、Product 和 Coupon Owner 的 HTTP 与应用服务；不跨域读写表。
- Channel 复用已合入的稳定资源 ID、ETag、幂等键和归档回读能力；本轮修正正常列表错误携带 `include_archived=true`，保留旧详情和历史读取。
- 普通商品由本地生命周期新增终态 `archived`；周期商品复用既有归档命令。
- 问卷新增数据库/领域终态 `archived`，保留不可变版本与答卷外键。
- 问卷 DELETE 是 CAS 命令：确认前 UI 冻结 `id`、`expected_version` 与 `Idempotency-Key`，请求体必须是 `{expected_version}`；服务端不在 DELETE 时补读“最新版本”。同键同体回放原收据，陈旧版本为 409。归档定义在编辑页只读，不能通过更新、启停或复制恢复原对象。
- Product 的正常发现与历史读取分开：普通/周期商品的默认列表、总数和新选择器排除 `archived`，但 `ReadProductTargets` 继续为既有优惠券、订单和历史展示解析已归档商品名称。对当前新选择/公开购买的单目标读取拒绝归档商品。
- 优惠券归档限定在模板/发放定义；不得批量改写实例。当前 Owner 的结账预留只接收 `published` 模板，因此确认文案须明确：归档停止领取和后续使用，已下单/已核销记录保留。
- 前端复用管理端单壳、冻结 donor 的当前列表页面以及现有 `confirmBox`。适配层只装配确认与 Owner HTTP 调用，不保存业务状态。

## 验收

- 确认后 Owner 回读为 archived，刷新后不出现在正常列表；总数和最后一页回退正确。
- 取消不发写请求；重复点击只使用同一逻辑意图；403/409 明确反馈；网络未知先回读、不盲写新幂等键。
- 对每种资源验证历史读取仍可用，而新的公开读取、选择、执行、分享或提交被拒绝。
- 问卷与商品 UI 测试必须实际挂载冻结模板：确认取消零写，确认命令冻结版本，重试复用同一 body/key，成功列表回读后该行不再渲染。产品与券的尾页、Coupon sidebar 的 list/count/exact-ID 一致性以 Owner 存储测试覆盖。
- 不以静态前端过滤或成功提示作为验收证据；使用隔离 PostgreSQL fixture 和实际挂载 UI 的读回。
