# PRD-01 客户同步与目录补齐

状态：批准开发；执行前必读 00-control.md。模型 Terra high；沿用“用户列表”。

## 1. 基线与分类

沿用 `docs/04-PRD-客户激活与客户列表.md` 和 `docs/08-PRD-客户档案与跨域详情接线.md` 的已批准相关行为；以总控 pin 的 V3/AI-CRM 为当前基线。旧版客户同步、客户列表和资料读取是行为供体，现有 V3 customer、wecom、identity 及客户页面优先复用。

OneID：可信企微身份解析/显式建客，读取 canonical Customer；手机号仅按现有可信等级附着。持久化：Provider read + River 内部任务 + PostgreSQL UoW；不涉及企微写效果。

## 2. 当前差异

| 能力 | 基线事实 | 本轮工作 |
|---|---|---|
| 全量同步与目录 | 已有实现，生产曾完整成功 | 冻结正常多页行为并验证恢复 |
| 连续运行 | 后续轮次出现 provider_unavailable/retry_exhausted | 用安全失败证据定位原因，修复确定的代码缺陷；配置问题只列部署待办 |
| 员工关系、资料与观察 | 已有 Store/Port，部分成果仍在旧对话工作区 | 对照最新主线补确实缺失的接线，不整体带入脏工作区 |
| 状态展示 | River completed 不等于业务轮次 succeeded | 列表/详情使用业务轮次真实状态和最近成功时间 |

## 3. 用户流程与需求

1. 管理员启动全量同步，幂等重复返回原轮次；不创建两个并发全量轮次。
2. 枚举授权成员、分页获取客户资料，每批只提交成功验证的资料、身份、关系、收据与游标。
3. 进程重启从已提交进度继续；失败保留已成功数据，只有完整成功轮次可执行 stale 对账。
4. 回调新增、资料修改、关系删除沿用普通入客机制，重放不重复建客；欢迎语不由本板块前置阻塞。
5. 客户列表、已有筛选、详情、手机号脱敏/受控揭示和同步进度复用原页面；不扩展 Customer 360。
6. Provider disabled、权限错误、临时失败、重试耗尽分别表达，不显示伪成功；缺少凭据不触发无限重试。

## 4. Owner、接口与数据

- wecom 拥有目录来源、同步轮次及关系观察；customer 拥有客户目录读模型；identity 拥有身份。沿用现有 Ports，不交叉写表。
- 保持现有 `/api/admin/customers`、`/api/admin/customer-sync-runs` 与详情接口兼容；仅增加必要的状态字段，不建立第二套同步 API。
- 本页身份/资料/收据/事件/游标同事务；调用企微不得持有事务。
- declared 手机号不升级 verified，不以手机号隐式建客。现有手机号导入工具只做隔离测试，所有输入桶可对账。

## 5. 测试及验收

- 旧版列表/筛选/分页/错误态对照；保持 frozen donor 文件哈希。
- 本地 Provider 模拟多员工、多页、重复客户、429/5xx、权限失败、无效响应；验证并发建客只有一个根。
- PostgreSQL 故障注入验证整批回滚、cursor 不前进、重启只继续未完成批次；失败轮次不得批量 stale。
- 业务 failed_terminal 不得因 River job completed 被展示为成功；重复触发及定时入口幂等。
- 手机号导入重复/跨 scope/冲突/非法输入收据与 no-store/RBAC/审计测试。
- 返回实现 PR、精确 HEAD、相关 race 与 PostgreSQL 结果。生产重新同步、启用配置、连续三周期观察均列待办，不在本轮执行。

## 6. 排除与协作

不改渠道欢迎语接纳路径，不做通用客户标签写、负责人迁移、聊天 UI、全平台调度重构。与 08 的 callback 公共文件修改须先报总控。

## 7. 总控补充验收定位

PR133/c3195e2 对错误分类和失败状态已有PG16 CI证据，但完整测试还需两员工多页、同客户跨页关系保留、第二页失败后的实际恢复继续，不只检查cursor值。结合PR135验证无Customer时欢迎独立执行与普通入客只有一个根。

[企微官方错误码说明](https://developer.work.weixin.qq.com/document/path/90313)原文已只读取得，明确HTTP成功响应中的errcode=-1属于系统繁忙、暂不可用并建议有限重试；它不能归为永久 provider_response_invalid。补相应Provider读取分类及持久恢复测试，复用现有有限重试内核，不扩展到Provider写入盲重试。
